## 使用

1. 完整解壓縮 ZIP。
2. 開啟 **ELON下載.exe**，並保留旁邊的 `tools` 資料夾。
3. 貼上公開影片連結，選擇格式與儲存位置，按「開始下載」。

可攜版已包含執行階段與影音元件，不需要另外安裝 .NET、Python 或 FFmpeg。

## 功能

- MP4 最高畫質、1080p 以下、720p 以下，以及 MP3 音訊。
- 下載進度、取消、開啟資料夾、更新下載核心。
- 記住格式與儲存位置，同名檔案不覆寫。
- 專屬藍色 ICON 與右下角作者署名。

網站支援來自 [yt-dlp](https://github.com/yt-dlp/yt-dlp)。來源權限、網站改版與平台限制可能影響下載；此版本未整合登入或瀏覽器 Cookie。

隨附元件來源及授權文件位於程式包內的 `THIRD-PARTY-NOTICES.md`、`tools/versions.json` 與 `tools/licenses`。每次發佈提供 SHA256 檢查碼。
